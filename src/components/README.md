# Shared components

Shared, reusable UI lives here once the design system starts. Keep the
directory empty until an issue/ADR approves the first primitives.

- Default to Server Components.
- Add `"use client"` only at leaves.
- Handle loading, empty, error, and disabled states.
- Use tokens from `src/app/globals.css`.
- See `docs/design-system.md` and `docs/ui-conventions.md`.
