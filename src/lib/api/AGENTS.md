# Generated API client

Everything in this directory except `AGENTS.md` is generated by Orval from
`contracts/public.openapi.yaml`.

- Do not edit generated files by hand.
- Do not add hand-written helpers here; put them in `src/lib/` instead.
- Change the contract, then run `npm run contract` from the repo root.
- Review the contract diff, not the generated diff.
- `generated.msw.ts` and `generated.faker.ts` are for tests and local MSW only.
  Never import them into application code.

See `docs/contract.md` and `docs/api-client.md`.
