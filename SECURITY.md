# Security Policy

This is a public repository. Do not report vulnerabilities in a public issue.

Follow the organization policy:

- <https://github.com/G6CODERS/.github/blob/main/SECURITY.md>

Include the affected commit, route, reproduction steps, and impact. Do not
include live credentials, personal data, or paid content in the report.

## AI agents

- Follow `AGENTS.md` and `docs/security-model.md`.
- Never read or commit `.env` files, credentials, or real student data.
- Do not force-push, rewrite `main`, or run destructive git commands.
- Report suspected vulnerabilities privately, not in an agent transcript or
  public issue.
