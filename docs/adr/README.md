# Architecture decision records

ADRs capture decisions that are expensive to reverse or easy to forget. They
are short: context, decision, consequences, alternatives.

## Format

Copy `template.md` to `NNNN-short-slug.md` and open a PR. ADRs are immutable
once accepted; supersede with a new ADR instead of rewriting history.
